World rules and players

  • World type and rules (Standard, Custom or Creative, and their settings) are stored inside the save. To use custom rules, create the world in the game with the settings you want, then upload its save here.
  • In game, anyone who enters the admin password from Settings opens Settings → Server Management to manage the running server and its players.
  • Players find the server under Worlds → Public by searching for the exact default world name, including capitals. A world password (Settings) limits who can join.
  • Backups: the Backups tab takes snapshots of all saves and the game's config while the server is stopped.

Install or update Dragonwilds

Downloads the official Linux dedicated-server files through Valve SteamCMD. Progress and errors appear in Console.

The first download is several gigabytes. UDP ports 7777–7782 must be published and forwarded for players to join. If SteamCMD reports that anonymous access is unavailable, claim the free dedicated-server tool in Steam first.

World saves, discovery and troubleshooting

Finding the server: In Dragonwilds, open Worlds → Public and search for the exact default world name. Search is case-sensitive. Keep the server and game client on matching versions.

Worlds: Use the Worlds tab to upload a save from your PC, choose which world loads, start a new world, or restore an older one. The server loads the newest save; with none, it creates a new Standard world named after the default world name.

Logs: RSDragonwilds/Saved/Logs/RSDragonwilds.log. Realmkeeper's Console also shows server and SteamCMD output.

Config: Realmkeeper writes DedicatedServer.ini under the Linux config directories before launch. Stop the server before making manual edits; the game may discard INI changes made while it is running.

Server settings

Dragonwilds dedicated-server settings. Written to DedicatedServer.ini when the server is stopped or next starts. Do not edit the INI while the game is running; the game can discard those changes.

Find your Owner ID at the bottom of the in-game Settings menu. Players find the server under Worlds → Public by searching for the exact world name, including capitalization. World saves are stored under RSDragonwilds/Saved/Savegames.

Network: forward the server's UDP port (7777 by default). The official RAM baseline is 2 GB plus about 1 GB per player (up to 6 players).

Networking. The container publishes a port range. Each server needs a different port in that range.

RuneScape: Dragonwilds currently supports up to 6 players. The game-managed player limit is not changed by this panel.
